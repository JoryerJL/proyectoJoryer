## 📖 Descripción

Sitio web **estático** que funciona como portafolio personal. Está construido
únicamente con **HTML5** y **CSS3**, sin frameworks ni dependencias externas.
La página principal presenta un menú de navegación, un título de bienvenida y
una galería de imágenes que enlazan a las distintas secciones del portafolio.

> 💡 Es un proyecto académico (Tópicos de Desarrollo de Aplicaciones — Unidad 1)
> pensado para practicar HTML, CSS y control de versiones con Git.

---

## 🛠️ Tecnologías

| Tecnología | Uso en el proyecto |
|:----------:|:-------------------|
| 🧱 **HTML5** | Estructura y contenido de las páginas (`index.html`) |
| 🎨 **CSS3** | Estilos y maquetación (`css/style.css`) |
| 🖼️ **Imágenes JPG** | Recursos gráficos de las secciones (`img/`) |
| 🔧 **Git** | Control de versiones del proyecto |

---

## 🎨 Estilos definidos

El archivo `css/style.css` define las siguientes clases:

- `.header` — Encabezado con el correo de contacto.
- `.menuHorizontal` — Menú de navegación centrado (color *blueviolet*).
- `.titulo` — Título principal centrado (color azul).
- `.tablaPrincipal` — Tabla que contiene la galería de imágenes.
- `.footer` — Pie de página con los derechos reservados.

---

## 🚀 Cómo verlo

No requiere instalación ni servidor. Basta con abrir el archivo en el navegador:

```bash
# Desde la carpeta del proyecto
open index.html      # macOS
```

> 💡 También podés arrastrar `index.html` directo a tu navegador.
